# Simulation package

This package contains the simulator, baseline policy, Gymnasium environment, evaluator, plot generator, and interactive dashboard. Start from the repository root and use module commands so imports resolve consistently:

```bash
python -m simulation.eval
python -m simulation.plot_trajectory
python -m simulation.dashboard
```

The evaluator currently characterizes the heuristic only. Read [the root README](../README.md) for system scope and [the simulator model notes](../docs/design/simulator_model.md) for physical assumptions and limitations.
